$ dotnet run

================================================================================
⚠️ TROUBLESHOOTING RÁPIDO
================================================================================

PROBLEMA: Porta 5000 em uso
SOLUÇÃO:  netstat -ano | findstr :5000
          taskkill /PID <PID> /F

PROBLEMA: Docker não inicia
SOLUÇÃO:  Verificar se Docker Desktop está rodando

PROBLEMA: Erro de conexão PostgreSQL
SOLUÇÃO:  Aguardar 30 segundos para PostgreSQL iniciar
          docker-compose ps

PROBLEMA: Erro na compilação
SOLUÇÃO:  dotnet clean && dotnet restore

PROBLEMA: Migrations não funcionam
SOLUÇÃO:  dotnet ef migrations remove --force
          dotnet ef migrations add InitialCreate

PROBLEMA: Porta já em uso (PostgreSQL)
SOLUÇÃO:  docker-compose down -v
          docker ps -a
