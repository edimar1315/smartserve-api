🎯 Próximos Passos (Execute em Ordem)

  1. Verificar Ferramentas

    Execute o script de diagnóstico para validar instalações

    .\diagnose.bat
  2. Compilar Projeto

    Compila, restaura dependências e cria a migration inicial

    .\setup.bat
  3. Iniciar Containers

    Inicia PostgreSQL, Redis, RabbitMQ e Adminer

    .\start-containers.bat
  4. Aplicar Migrations

    Cria as tabelas no banco de dados

    cd SmartServe.Api
    dotnet ef database update
  5. Executar API

    Inicia o servidor de desenvolvimento

    dotnet run

    API disponível em: http://localhost:5000

💡 Dicas Úteis

🔄 Resetar Banco de Dados

Se algo der errado, você pode limpar tudo:

.\stop-containers.bat

E depois recomeçar do passo 3.

📝 Editar Configurações

Abra SmartServe.Api/appsettings.json para alterar:

  • Connection strings
  • Logging levels
  • Credenciais externas

🔍 Verificar Status

Veja se os containers estão rodando:

docker-compose ps
