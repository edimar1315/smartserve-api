RELACIONAMENTOS DO BANCO DE DADOS (Entity Relationships)
════════════════════════════════════════════════════════════════════════════

User (TPH Inheritance)
│
├─ Professional
│  ├─ 1─→∞ Specialization (via ProfessionalSpecialization)
│  └─ 1─→∞ Proposal
│
└─ Client
   └─ 1─→∞ ServiceRequest

ServiceRequest
│
├─ FK→ Client (many ServiceRequest per Client)
├─ FK→ Specialization
├─ 1─→∞ Proposal
└─ 1─→∞ Payment

Specialization
│
└─ ∞←─1 Professional (via ProfessionalSpecialization)

ProfessionalSpecialization (Junction Table)
│
├─ FK→ Professional
└─ FK→ Specialization

════════════════════════════════════════════════════════════════════════════

ÍNDICES DO BANCO (Performance Optimization)
